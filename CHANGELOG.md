# Changelog

## v0.1.0

Initial public release.

### Added

- TypeScript CLI for scanning MCP and AI agent configuration files.
- Risk scoring and text reports.
- JSON output for automation and dashboards.
- GitHub Actions annotation output.
- Reusable composite GitHub Action.
- Detection rules for shell launchers, package runners, broad filesystem access, inline secrets, risky startup arguments, and prompt-injection language.
- Safe and unsafe example projects.
- Automated tests, CI, security policy, and contribution guide.
