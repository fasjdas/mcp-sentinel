# Security Policy

## Reporting a Vulnerability

If you find a security issue in MCP Sentinel, please open a private report through GitHub Security Advisories:

https://github.com/fasjdas/mcp-sentinel/security/advisories/new

If that is not available, open an issue with minimal public detail and we will move the discussion to a private channel.

## Scope

MCP Sentinel is a static configuration scanner. Findings are best-effort signals, not a guarantee that a configuration is safe or unsafe.

Please include:

- The affected MCP or agent configuration shape.
- The expected risk classification.
- A minimal reproduction if possible.
- Whether the issue causes false negatives, false positives, or unsafe behavior in the CLI.
